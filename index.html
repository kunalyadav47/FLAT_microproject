Theoretical Laboratories: Pumping Lemma Adversary Games

Interactive proofs by contradiction demonstrating that languages are NOT regular (Module 2) or NOT context-free (Module 3).

Adversary Game Pumping Exponent i Non-Regularity Proofs

1️⃣ Regular Language Pumping Lemma: L = { aⁿ bⁿ }

Suppose $L$ is regular. Then $\exists p \ge 1$ such that $\forall w \in L$ with $|w| \ge p$, $w$ can be decomposed into $w = xyz$ where $|xy| \le p, |y| \ge 1$, such that $x y^i z \in L$ for all $i \ge 0$.

i = 0 (Pumping Down)

2️⃣ CFL Pumping Lemma: L = { aⁿ bⁿ cⁿ }

If $L$ is context-free, any string $w = a^p b^p c^p$ can be split into $u v x y z$ with $|vxy| \le p$ and $|vy| \ge 1$, so $u v^i x y^i z \in L$ for all $i \ge 0$.

i = 2 (Pumping Up)

Abstract

This microproject presents a complete, educational software visualizer for Formal Language and Automata Theory spanning all three curriculum modules: Formal Languages & RegEx (Module 1), Finite Automata & Minimization (Module 2), and Context-Free Grammars & Pushdown Automata (Module 3). Designed with zero external dependencies and rigorous theoretical rigor, the platform bridges abstract mathematical definitions with dynamic visual feedback.

Key Methodologies Implemented

  • Thompson's Construction: Translates regular expressions into $\epsilon$-NFA using compositional syntax sub-gadgets.
  • Subset Construction: Uses powerset $\epsilon$-closure search to synthesize deterministic finite automata.
  • Myhill-Nerode Table-Filling: Minimizes DFA states through systematic distinguishability matrix fixed-point iteration.
  • Context-Free Grammar & PDA: Generates leftmost derivations, tree visualizations, ambiguity proofs, and pushdown stack traces.
