2. Algorithmic Architecture & Mathematical Foundations

2.1 Regular Expressions to Finite Automata (Thompson's Construction)

Thompson's construction converts a postfix regular expression into an equivalent ε-NFA by inductively assembling state sub-gadgets. For concatenation, the accept state of the first operand connects to the start state of the second via an ε-transition. For union, new start and accept states branch and merge around the operands. For Kleene star, backward and forward bypass ε-transitions are established.

2.2 Subset Construction (NFA to DFA)

To convert an ε-NFA $M_N = (Q_N, \Sigma, \delta_N, q_0, F_N)$ to a deterministic automaton $M_D$, we compute the ε-closure of state subsets. Starting with $S_0 = \epsilon\text{-closure}(q_0)$, each DFA state represents a distinct subset of NFA states. For every alphabet symbol $a \in \Sigma$, the target state is defined by $\delta_D(S, a) = \epsilon\text{-closure}(\text{move}(S, a))$.

2.3 DFA State Minimization (Table-Filling / Myhill-Nerode)

Unreachable states are first pruned via BFS traversal from $q_0$. The triangular distinguishability table $\mathcal{M}(p, q)$ initializes pairs where exactly one state is accepting. Inductive fixed-point iterations inspect all symbols $a \in \Sigma$: if $\delta(p, a)$ and $\delta(q, a)$ are already marked as distinguishable, then $(p, q)$ is marked. Unmarked pairs upon convergence form equivalence classes which are merged to construct the quotient DFA.

2.4 Pushdown Automata (PDA) Dynamics

A Pushdown Automaton $M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$ extends finite-state control with an unbounded LIFO stack. For language $L = \{a^n b^n \mid n \ge 1\}$, the simulator pushes $A$ onto the stack for every $a$ read, and pops $A$ for every $b$. Acceptance occurs when the input is fully consumed and the stack returns to initial symbol $Z_0$ in an accepting state.
